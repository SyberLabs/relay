# Relay by SyberLabs

Your job search should remember what you've done.

Relay is an early SyberLabs product for people using AI to research jobs and prepare applications. It brings repeated postings, source history, missing facts and exact drafts into one review workspace.

Import research from Notion, exchange packets with Grok Bot, or prepare a draft with Claude. Review the actual words before using them. Keep interview notes without resetting your application status.

Available now: the application workspace and local command integrations. Account connections require setup. Autonomous hunting and application sending are not included in this release.

Explore the code and setup guide: https://github.com/SyberLabs/relay

No customer counts, hiring outcomes or throughput improvements have been claimed. This copy is suitable for the repository launch; no social post has been sent.
