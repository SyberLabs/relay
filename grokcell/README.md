# GrokCell

Maintained source for four published Grok Bot templates. Each package includes the Bot profile, complete skill instructions, a public Bot link, and bounded behavior evidence.

## Bots

- [First Principles](bots/first-principles/README.md) — clarify the problem, question assumptions, and choose a next step.
- [Product Ideation](bots/product-ideation/README.md) — turn customer problems into ideas and inexpensive demand tests.
- [Red Flag](bots/red-flag/README.md) — check plans, code, and AI answers for consequential failures and unsupported claims.
- [Garbage Collector](bots/garbage-collector/README.md) — simplify code while preserving required behavior.

Use the [Bot guide](bots/README.md) to choose, set up, and check a template. See [Contributing](CONTRIBUTING.md) to propose an improvement.

For source improvements, open a [pull request in `sdcarlson/grokcell`](https://github.com/sdcarlson/grokcell/pulls).

## Source, evidence, and history

The checks record bounded observations, not guarantees of model behavior. Public Bot links were verified during their original publication sessions on September 4–5, 2026; they do not establish marketplace catalog admission. The files in this repository are maintained source, while public Bots are separately deployed snapshots. A source change requires a separate inspected publication step to update a public Bot.

The retired fifteen-skill coordination suite remains available in the [baseline commit history](https://github.com/sdcarlson/grokcell/tree/dd98523f2b08be9fc4a6fc0795745cf87fb54173).
